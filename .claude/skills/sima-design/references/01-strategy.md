# 01 — Brand Strategy

> **اقرأ هذا الملف فقط عند:** بدء discovery لعلامة جديدة، أو إعادة تموضع (repositioning)، أو حين يطلب العميل "brand strategy" قبل أي visuals.

## Discovery Brief (إلزامي قبل أي اقتراح بصري)

```
الأساسيات: الاسم، القطاع، Mission، Vision، Core Values
الجمهور: العميل المثالي (ديموغرافيا + سيكوغرافيا)، أين يتواجد، مخاوفه
المنافسة: المنافسون الرئيسيون، UVP، ما تتجنّبه بصرياً
الشخصية: لو علامتك شخص — صفها بـ5 كلمات
التقني: نقاط الاستخدام (ويب/طباعة/بيئة)، قيود ألوان/خطوط، الميزانية والـ timeline
```

**Socratic questions** (اطرحها واحداً واحداً، لا 5 معاً):
1. "ما المشكلة الحقيقية التي يحلّها منتجك؟" (ليس ما يفعل، بل لماذا يهم)
2. "من الجمهور الذي *لن* تستهدفه؟" (الإقصاء يوضّح التموضع)
3. "ماذا سيقول عملاؤك في عام 2030 عنك؟" (vision pull)
4. "ما المنافس الذي تخشى تشابهك معه؟" (anti-pattern)
5. "إن اضطُررت لاختيار كلمة واحدة — ماذا تريد للعالم تذكّرها؟"

## Positioning Map

```
محور أفقي: تقليدي ←—————→ حديث
محور رأسي: فاخر    ←—————→ اقتصادي
ضع المنافسين → الفراغ = تموضعك
```

## Brand Archetypes (Jung — 12)

| Archetype | الصفات | أمثلة |
|-----------|---------|-------|
| Hero | قوة، شجاعة | Nike, Adidas |
| Sage | معرفة، حقيقة | Google, TED |
| Creator | خيال، ابتكار | Apple, LEGO |
| Caregiver | دفء، حماية | J&J |
| Explorer | حرية، مغامرة | Jeep, Patagonia |
| Outlaw | تمرّد | Harley-Davidson |
| Ruler | فخامة، سلطة | Rolex, Mercedes |
| Jester | مرح، خفة | M&M's |
| Lover | جاذبية، أناقة | Chanel |
| Innocent | نقاء، أمان | Dove, Coca-Cola |
| Magician | تحويل، إلهام | Disney, Tesla |
| Everyman | تواضع، انتماء | IKEA |

**اختر واحداً أساسياً + ثانوياً (لا 3+).** Audi = Ruler primary + Sage secondary.

## 3-Word Test

```
Apple → بسيط، مبتكر، إنساني
Nike → قوة، إلهام، حركة
Rolex → فخامة، دقة، خلود
علامتك → ____ / ____ / ____
```

هذه الـ 3 كلمات تصبح **مرشّح كل قرار تصميمي لاحق**.

## Tone of Voice (محاور لا أطراف)

```
رسمي ←—•—→ غير رسمي     جادّ ←—•—→ مرح
مُلهِم ←—•—→ واقعي         متحدّي ←—•—→ دافئ
```

اختر موضعاً (•) **بعيداً عن الطرفين** وابقَ فيه عبر كل copy.

## Brand Platform Output

```
الغرض (Purpose):     "نحن نوجد من أجل ___"
القيم (Values):      1. ___  2. ___  3. ___
الوعد (Promise):     "_______________"
الشخصية:             Archetype + 3 كلمات
الجمهور:             Persona واحدة (لا 5)
التموضع:             "بالنسبة لـ {audience}، نحن الـ {category} الذي {differentiator}"
```

## Anti-patterns

- ❌ القفز للـ visuals قبل اكتمال platform.
- ❌ Archetype 3+ (يساوي لا archetype).
- ❌ "نخدم الجميع" = "لا أحد".
- ❌ نسخ tone من منافس بدلاً من تمييز.
